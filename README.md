# 대주단 제출용 사업계획서 앱

시행사가 대주단에 낼 사업계획서를 입력값만으로 만드는 웹앱. 특정 사업장을 전제하지 않는다.

- 입력 → 사업수지(기말현금 · DSCR · LTV · 상환 한계 · 민감도) 계산
- 사업대상지(시도 · 시군구) 기준 공공데이터 시장 분석
- 목차 1~7장 사업계획서 · 차트 · A4 인쇄

## 실행

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm test` | 검산 테스트 (`node --test`, 별도 테스트 도구 없음) |
| `npm run typecheck` | 타입 검사 |
| `npm run lint` | ESLint |
| `npm run build` | 프로덕션 빌드 (인증키 없이도 통과) |

## 인증키 (공공데이터포털)

`.env.local`에 아래 한 줄을 둔다. 키는 서버 코드에서만 읽고, 응답 · 로그 · 브라우저 번들에 노출하지 않는다.

```
DATA_GO_KR_KEY=발급받은_인증키
```

Vercel에 배포할 때는 같은 이름으로 환경변수를 등록한다. **`NEXT_PUBLIC_` 접두사를 붙이지 않는다.**

쓰는 공공데이터 (주소 · 파라미터는 `api_docs/` 기술문서 기준)

| API | 용도 |
| --- | --- |
| 행정안전부 법정동코드 | 지역 이름 → 시군구 코드 확인 (서버에서만) |
| 국토교통부 아파트 분양권전매 실거래가 | 분양권 웃돈 |
| 국토교통부 아파트 전월세 실거래가 | 84㎡ 신규 전세 |
| 한국부동산원 청약홈 분양정보 · 경쟁률 | 인근 신규 분양가 · 미달 · 잔여세대 |

## 구조

| 경로 | 내용 |
| --- | --- |
| `lib/calc.ts` | 사업수지 계산 (순수 함수) |
| `lib/market.ts` | 공공데이터 해석 · 제외 규칙 · 시장 분석 표 |
| `lib/server/datagokr.ts` | 공공데이터 호출 (`server-only`, 캐시 하루 · 법정동코드 30일) |
| `lib/chart.ts` · `components/charts/` | 축 계산 · SVG 차트 (차트 라이브러리 없음) |
| `components/PlanApp.tsx` | 입력 · 결과 화면 |
| `app/api/` | Route Handler (브라우저는 지역 이름만 보낸다) |

작업 규칙은 [CLAUDE.md](CLAUDE.md) 참고.
